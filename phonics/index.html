⏱️ เรียนวันละ 10–15 นาที

  • วันละ 2–3 เสียงใหม่ + ทบทวนเสียงเก่า
  • ทำ ท่ามือพร้อมกัน ทุกครั้งที่ออกเสียง (ร่างกายช่วยจำ)
  • จบด้วยเกม 1 เกม ให้รู้สึกสนุกเสมอ
  • ชมความพยายาม ไม่ใช่แค่ความถูกต้อง 💛

🔤 "เสียง" ไม่ใช่ "ชื่อ" ตัวอักษร

Phonics สอนเสียงที่ตัวอักษรทำ เช่น s = "ซ์ซ์ซ์" ไม่ใช่ "เอส", m = "ม์ม์ม์" ไม่ใช่ "เอ็ม"

ระวัง อย่าเติมสระ ต่อท้าย เช่น t ต้องเป็น "ท์" สั้นๆ ไม่ใช่ "เทอะ" เพราะจะทำให้ผสมคำผิด (t-a-p กลายเป็น เทอะ-แอะ-เพอะ)

🧩 วิธีผสมเสียง (Blending)

  1. ชี้ทีละตัว พูดทีละเสียง: c – a – t
  2. พูดเร็วขึ้น ลากเสียงติดกัน: caaat
  3. พูดเป็นคำ: cat! 🐱

เด็ก 9 ขวบเรียนเร็ว ลองท้าให้แยกเสียงกลับ (Segmenting): "dog มีเสียงอะไรบ้าง?" → d-o-g

🇹🇭 เสียงที่เด็กไทยต้องระวัง

เสียงมักออกผิดเป็นเคล็ดลับ
thด / ท / ซแลบลิ้นออกมานิดหน่อย
vว / บฟันบนกัดปากล่าง
zซจับคอ ต้องสั่นเหมือนผึ้ง
r / lสลับกันr ลิ้นไม่แตะ / l ลิ้นแตะ
sh / chช เหมือนกันsh ลากยาว / ch สั้น
เสียงท้ายกลืนหายcat, bag, box ต้องได้ยินตัวท้าย
g, j, d, bไม่ก้องจับคอ ต้องสั่น

🙌 ทำไมต้องมีท่ามือ?

ท่ามือช่วยให้เด็กจำเสียงด้วย ตา หู และร่างกาย พร้อมกัน (Multi-sensory) เด็กที่ลืมเสียงจะนึกออกเมื่อทำท่า

เคล็ดลับ: เปิด "กระจกวิเศษ" (กล้อง) ในการ์ดเสียง ให้ลูกเห็นตัวเองทำท่า และดูปากตัวเองตอนออกเสียง

📅 ตัวอย่างตาราง 1 สัปดาห์

  • จ. เรียน 3 เสียงใหม่ + ท่ามือ
  • อ. ทบทวน + เกมนักสืบเสียง
  • พ. เรียน 3 เสียงใหม่ + อัดเสียงเทียบ
  • พฤ. เกมผสมเสียงเป็นคำ
  • ศ. คู่แฝดหลอกหู + พูดให้ไมค์ฟัง
  • ส.–อา. แข่งกับพ่อแม่ 🏆 แลกสติกเกอร์

🗣️ ใช้เสียงคนจริง

แอปเลือกเสียงตามลำดับนี้: 👩 เสียงพ่อแม่ → 🧑‍🏫 เสียงคนจริงที่แนบมา → 🤖 เสียงสังเคราะห์

วิธีอัดเสียงพ่อแม่: เปิดการ์ดเสียง → เลื่อนลงไปที่ "เสียงต้นแบบจากพ่อแม่" → กด 🎙️ อัด (อัดได้ทั้งเสียงเดี่ยวและคำตัวอย่าง)

ต้องเปิดเว็บผ่าน https หรือ localhost และอนุญาตไมโครโฟน เสียงเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น
