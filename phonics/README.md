# 🐱 Meo Phonics — เรียนโฟนิกส์กับพ่อแม่

เว็บไซต์แบบ interactive สำหรับเด็กประมาณ 9 ขวบ ใช้เรียนโฟนิกส์ร่วมกับพ่อแม่ เน้น **ออกเสียงให้ถูก**, **ทำท่ามือ** และ **ความสนุก**

## วิธีเปิดใช้งาน
ไม่ต้องติดตั้งอะไรเพิ่ม เพราะเป็นไฟล์ HTML/CSS/JS ล้วน

```bash
cd phonics
python3 -m http.server 8000
# เปิด http://localhost:8000 ใน Chrome หรือ Edge
```

> กล้องและไมโครโฟนใช้ได้เฉพาะเมื่อเปิดผ่าน `localhost` หรือ `https` (เช่น GitHub Pages)

## มีอะไรบ้าง
- **การ์ดเสียง 40 เสียง** แบ่งเป็น 7 ด่าน (s a t p i n → ar or er ow oi) แต่ละการ์ดมี
  - 🔊 เสียงตัวอย่างและคำตัวอย่าง
  - 👄 วิธีวางปากและลิ้น พร้อม ⚠️ จุดที่เด็กไทยมักออกเสียงผิด
  - 🙌 ท่ามือประจำเสียง และ 🪞 "กระจกวิเศษ" ที่เปิดกล้องให้เด็กเห็นตัวเองตอนทำท่า
  - 🎙️ อัดเสียงตัวเองแล้วฟังเทียบ และ ✅ ให้ไมค์ช่วยตรวจ (Speech Recognition)
- **เกม 6 เกม**: นักสืบเสียง, ผสมเสียงเป็นคำ, คู่แฝดหลอกหู (th/s, v/w, r/l, sh/ch …), ท่ามือปริศนา, พูดให้ไมค์ฟัง และแข่งกับพ่อแม่
- **ดาว ⭐ / สติกเกอร์ / streak 🔥** บันทึกไว้ในเครื่อง (localStorage)
- **คู่มือพ่อแม่**: ตารางเรียน วิธีสอนผสมเสียง (blending) และตารางเสียงที่เด็กไทยต้องระวัง

## เสียงคนจริง
แอปเลือกเสียงตามลำดับ: **👩 เสียงพ่อแม่** (อัดในการ์ดเสียง เก็บใน IndexedDB ของเครื่อง) → **🧑‍🏫 ไฟล์เสียงคนจริง** ที่ลงทะเบียนใน `js/audio-manifest.js` → **🤖 เสียงสังเคราะห์**

เพิ่มไฟล์เสียงเอง: วางไฟล์ไว้ใน `audio/` แล้วเพิ่ม `"sound:sh": "audio/sound-sh.mp3"` หรือ `"word:ship": "audio/word-ship.mp3"` ใน `AUDIO_FILES`
ใช้เฉพาะไฟล์ที่มีสิทธิ์ใช้งานถูกต้อง (เช่น CC0 / CC BY / CC BY-SA จาก Wikimedia Commons) และใส่ที่มาใน `AUDIO_CREDITS` ทุกไฟล์ ไม่ควรตัดเสียงจากวิดีโอ YouTube เพราะผิดเงื่อนไขการใช้งานและลิขสิทธิ์

## หมายเหตุ
- เสียงคนจริง 153 ไฟล์มาจาก Wikimedia Commons (ดาวน์โหลดด้วย `.github/workflows/fetch-phonics-audio.yml`) ได้แก่ สระเดี่ยว 10 เสียง และคำศัพท์ทุกคำในเว็บ ส่วนพยัญชนะเดี่ยวใช้เสียงจากคำตัวอย่าง เพราะไฟล์พยัญชนะใน Commons อัดพร้อมสระ
- ถ้าไม่มีไฟล์เสียงหรือเสียงพ่อแม่ จะใช้ Web Speech API ของเบราว์เซอร์แทน
- การตรวจเสียงพูดใช้ได้บน Chrome/Edge ส่วนเบราว์เซอร์อื่นจะให้พ่อแม่เป็นผู้ตัดสินแทน
